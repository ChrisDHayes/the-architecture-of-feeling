# The Architecture of Feeling
### Depeche Mode, Decoded · Christopher Hayes

An interactive research exhibit on Depeche Mode’s sonic identity, what can be measured, and what listening means.

## Enter the exhibit

**[Explore V3.0 — measured research beta](https://chrisdhayes.github.io/the-architecture-of-feeling/previews/v3-measured-beta/)** · [V2.9 — creative edition](https://chrisdhayes.github.io/the-architecture-of-feeling/archive/v2-9/) · [Measured Evidence Lab](https://chrisdhayes.github.io/the-architecture-of-feeling/research/acousticbrainz/Measured_Evidence_Lab.html)

The hosted links require GitHub Pages to be enabled and successfully deployed. If they are not yet available, open the [V3.0 HTML source](docs/previews/v3-measured-beta/index.html) and download it to run locally. GitHub’s file viewer displays source code rather than the interactive experience.

## About the editions

**V2.9 — the creative edition** is preserved unchanged. Its sonic tree and emotional relationships are illustrative, not measurements.

**V3.0 — the measured research beta** adds source-linked acoustic observations for 148 of 167 catalogue entries. The evidence remains provisional: recordings are not verified studio masters, and the beta is not approved for similarity, clustering, or mood claims. [Methods and publication gates](docs/V3_MEASURED_BETA_README.md) · [Evidence provenance](docs/research/acousticbrainz/preview_manifest.json)
